# Memory Match Adventure 🧠

A small, colourful animal memory matching game built with plain HTML, CSS and JavaScript. Made to play in a browser and easy to customise together.

## Features

- 8, 10 or 12 pairs across Easy, Medium and Hard difficulties
- Shuffle the cards every time a new game starts
- Move counter, timer and match counter
- Card flip animations and optional sound effects
- Win message with your final time and moves
- Responsive layout for desktop, tablet and mobile
- No backend, dependencies, build step or installation required

## Run locally on Windows

1. Clone the repository:

   ```bash
   git clone https://github.com/AshishDesk/MemoryMatchGame.git
   cd MemoryMatchGame
   ```

2. Open `index.html` in Chrome, Edge or Firefox.

That's it. You can also double-click `index.html` from File Explorer.

## Play

1. Choose a difficulty.
2. Select any card to reveal an animal.
3. Select another card and try to find its matching animal.
4. Remember the card positions when they do not match.
5. Find every pair to win!

Use **New game** to restart or shuffle at any time. Sound can be turned off using the sound button.

## Project files

- `index.html` - page structure and game controls
- `style.css` - layout, colours, responsive styles and animations
- `game.js` - shuffle, matching logic, timer, score and sound

## Hosting

This is a static website and can be hosted for free with GitHub Pages. No server is required.
